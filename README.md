# Description
This repository is a collection of practical assignments and project from the Artificial Intelligence course I have taken at SUT.

**Course**: [Artificial Intelligence, Dr. Rohban, Spring 2024](https://sut-ai.github.io/archive/spring2024/)

# Project

1. [Semantic Segmentation Using U-Net](P1%20U-Net/Notebook.ipynb)
+ Dataset: CARLA Self-Driving Car semantic segmentation
+ Architectures:
  * Vanilla U-Net (Encoder-Decoder with skip connections)
  * Attention U-Net (Attention Gates / Attention Blocks)
+ Training & Evaluation:
  * Cross-Entropy / Softmax loss
  * Mean Intersection over Union (mIoU)
+ Comparison & Analysis (U-Net vs. Attention U-Net)
